# キャンセル料・遅刻の設計方針（2026-10-03〜 検討中）

キャンセル・当日の時刻変更・遅刻の料金と扱いを、あとから迷わないように決めるための資料。規約（`docs/TERMS_DRAFT_2026-10.md` 第3〜5条）とシステム（`cf/v2/plan-calc.mjs` のキャンセル料、`cf/v2/billing.mjs` の申請と回答）は、この方針に合わせて直す。

## 1. 背景

- 当日のキャンセル・大きな遅刻・当日の時刻変更が続く生徒がいる。これまでは大目に見て、キャンセル料をほとんど請求してこなかった。
- 今の契約・運用では「体調不良」と言われると免除しがちで、実質的にいつでも無料で休める。授業の枠を空けて待つ講師の時間が無駄になり、ほかの生徒の枠も取れない。
- 遅刻は、出発が遅れた・電車が遅れたなど、もっと早く分かっていたはずなのに授業の直前に「30分遅れます」と連絡が来ることが多い。口頭で「分かった時点で連絡を」と伝えても直らない。

## 2. 原則（いちばん大事。料金はすべてこれを守るように決める）

1. **連絡が遅いほど、料金は同じか高くなる。** 早く連絡したほうが損になる場面を作らない。
2. **開始を遅らせる料金は、同じ時点でキャンセルする料金を超えない。** 遅らせるより休んだほうが安い、にしない。
3. **連絡のない遅刻は、連絡して遅らせるより高い。** 連絡したほうが得になる。
4. **料金は自動で決まり、例外は申請で扱う。** その場の判断で免除しない。特別な事情があるときは、保護者が申請し、塾が記録を残して答える。
5. **分かった時点で知らせる。** 遅れや休みが分かったら、その時点で連絡する。連絡の時刻を料金の基準にする。

## 3. 言葉

- **日時の変更・お休み**: 前日23時までの連絡。無料。
- **キャンセル**: 前日23時を過ぎてから、決定した授業を行わないことにすること。連絡のない欠席もキャンセル。
- **開始を遅らせる**: 当日、開始前に連絡して、開始時刻を後ろにずらし、授業は予定の長さで行うこと。塾の都合がつくときだけ。
- **遅刻**: 遅らせる連絡なしに、開始時刻より遅れて来ること。授業は予定の時刻に終わる。
- **単価 u**: 1回の授業料 F ÷ 1回の分数。

## 4. 料金の案（2026-10-03 改。★は決まったもの、ほかは案）

**取消料は「授業料」と「連絡を受けた時刻」だけで決まる。** ★

```
取消料 = 授業料 × (取り消した分数 ÷ 授業の分数) × 率(連絡を受けた時刻)
```

- キャンセルは授業の全部を取り消す（取り消した分数 = 授業の分数）。
- 開始を遅らせるのは、遅らせた分だけを取り消す。請求は **遅らせた分の取消料 ＋ 追加した分の授業料** ★。予定の長さで行えば「通常の授業料 ＋ 遅らせた分の取消料」。
- 連絡のない遅刻は、開始後に取り消したのと同じ（率 100%）。授業は予定の時刻に終わり、授業料は予定どおり。

率（a は当日早めの率）:

| 連絡を受けた時刻 | 率 |
|---|---|
| 前日23時まで | 0%（日時の変更・お休み） |
| 前日23時〜開始3時間前 ★ | a = 25% ★ |
| 開始3時間前〜開始時刻 ★ | a から 100% へ分単位でまっすぐ上がる ★ |
| 開始時刻以降・連絡なし | 100% |

- 3時間前〜開始の式: `率 = a + (100% − a) × (1 − 残り分数 ÷ 180)`。3時間前でつながるので、境目で急に上がらない。
- 例（a = 25%、90分・4,500円）: 3時間より前 1,125円 / 2時間前 2,250円 / 1時間前 3,370円 / 30分前 3,930円 / 開始以降 4,500円。
- 例（同じ授業を1時間前に30分遅らせ、予定の長さで行う）: 授業料 4,500円 ＋ 取消料 4,500 × 30/90 × 75% = 1,120円。
- 端数は10円未満を切り捨て ★。
- 原則の確認: 率は時刻とともに上がるだけ（原則1）。遅らせた分数は授業の分数以下なので、遅らせた分の取消料は同じ時刻のキャンセル料以下（原則2）。連絡なしの遅刻は率 100%（原則3）。

## 6. まだ決めていないこと（考え方と案）

### 6-1. 取消料の率（決定: 線形、a = 25%、10円未満切り捨て）
- 経過: 最初は「直前 50%」の段階案 → 開始に近づくほど 100% に近づける形に変更 → 線形に決定（2026-10-03）。
- **a（当日早めの率）をいくらにするか。** 今の規約案は「開始前の連絡は1回 1,000円」の定額。定額だと授業料と関係なく決まり、遅らせた分（一部の取消）にも使えないので、率に置き換える。今の 1,000円に近くなるように選ぶ（90分・4,500円なら 25% で 1,125円）。
- 体調不良（6-3）の「最低 1,000円」も、「当日早めの率 a」に置き換える案。
- 端数: 10円未満切り捨て（案）。今の規約案（第8条）は1円未満切り捨て。
- 「連絡を受けた時刻」: 保護者ページからの連絡はその送信時刻、LINE はメッセージの時刻。

### 6-2. 遅らせられないとき（上限・講師がいない）（決定: 塾が承諾したときだけ遅らせる）
- 料金は原則2で上限があるので、上限は「料金」ではなく「運営」で決める。
- 遅らせられない理由は2つ: **教室の終了時刻を過ぎる**（はっきり決まっている）、**担当できる講師がいない・ほかの授業と重なる**（その日の予定しだい）。
- 規約での表し方の案（どちらの理由でも同じ書き方にする）:
  1. 開始を遅らせる依頼は、**塾が承諾した場合に限り**行う。承諾するかどうかは塾が決め、理由を示す必要はない（終了時刻・講師の予定・ほかの授業など）。
  2. 塾が承諾しなかった場合は、**依頼はなかったものとして扱う**。元の時刻に来られなければ、その授業は、依頼の連絡を受けた時刻でのキャンセル（来たときは遅刻）として扱う。
  3. 承諾した場合は、承諾した開始時刻を記録し、遅らせる料金（6-1）を計算する。
- こうすると「遅らせられない日」の判断を一つずつ規約に書かなくてよい。「承諾されなければ、連絡した時点でキャンセルしたのと同じ」と一文で決まる。
- 本人の確認（2026-10-03）: 追加した時間は通常の授業料で計算するので、その日に延ばすか別の日に行うかの違いしかない。その日に延ばせなくても保護者の損にはならず、不満は出ないはず。→ この案で決定。

### 6-3. 体調不良などの扱い（公平さ）（決定: 受診の記録があれば免除の対象、なければ率 a = 25%）
- 回数の枠（月1回まで など）は、授業の多い生徒と少ない生徒で不公平になり、「枠の分は無料で休める」と受け取られるので使わない。
- 案: **体調不良でも、当日のキャンセルは最低でも「当日早め」の額（1,000円）にする**（全額免除ではなく、直前・開始後の分を軽くするだけ）。保護者からの連絡があることを条件にする。
- **全額免除は限られた場合だけ**: 事故・災害・忌引・学校保健安全法による出席停止の感染症 など。可能なら証明（診断書・登校停止の書類など）を求める。
- これなら授業回数に関係なく同じ扱いになり、「体調不良と言えば無料」にならない。

### 6-4. 公共交通機関の遅れ（決定: 証明があれば減額・免除の申請で扱う）
- 通常見込まれる数分の遅れと、それに伴う連鎖的な遅れは、やむを得ない事情に含めない（規約案の方針）。
- 大きな遅れ（例 15分以上）は、**遅延証明書（鉄道会社のサイトのデジタル版でよい）**を保護者ページから送ってもらうことを条件に、遅刻の扱いを軽くする（例: 塾の都合がつけば終了を延長する、または遅れた分を減額）。
- 決定（2026-10-03）: 遅延証明書など、**やむを得ない事情を客観的に示すもの**があれば、**減額・免除の申請**で取消料を減らす。終了を延ばすかどうかは 6-2 と同じ（塾が承諾したとき。追加した時間は通常の授業料）。減らし方は 6-5。

### 6-5. 「分かった時点で連絡する」の明文化（減額・免除の申請のとき）（決定: 3つの条件を満たせば免除）
- 決定（2026-10-03）: 免除は ① やむを得ない事情、② 客観的な資料、③ 分かってから30分以内かつ開始前の連絡、をすべて満たすとき。取消料は 0円（行った分の授業料はかかる）。満たさなければ、実際に連絡を受けた時刻で計算する。これが連絡遅延金の役目も果たす。
- 例（18:00〜19:30、90分・4,500円、1分 50円）:
  - 例1: 11:00 に通院が決まったのに無断欠席。後日、通院を理由に申請 → ③を満たさない。4,500円。
  - 例2: 15:00 に電車の乱れで遅れが確定、16:00 に 19:00 着と分かったのに無断で遅刻。後日、遅延証明書で申請 → ③を満たさない。行った30分 1,500円 ＋ 取り消した60分 3,000円（100%）＝ 4,500円。
  - 例3: 17:30 に電車が止まり、すぐ連絡、19:00 着、遅延証明書あり → 免除。行った30分の 1,500円だけ。申請しなければ 1,500円 ＋ 3,000円 × 87.5%（2,620円）＝ 4,120円。
- 申し出（案）: 表にない事情でも、保護者は理由を添えて申し出ることができ、塾は必ず回答して記録に残す。その申し出だけを特別に免除することはしない。表に加えるべきと塾が判断した場合は、**表を直し、その申し出にもさかのぼって当てはめる**（翌月からは全員に適用）。例外を作らず、ルールの方を直す。
- 所属先の都合を含めない理由: 自分で選んで入った所属先の予定であること。だいたいの見当がつき、早めに連絡できること。塾から確かめる方法がないこと。早く連絡すれば率は低く済み、同じことが続く場合は曜日・時刻を変える相談で解決する。
- 以下は検討の経過:
- 本人の考え（2026-10-03）: これは **特別な事情で減額・免除を申請する場合** の決まり。正当な理由があっても、連絡が不当に遅れた場合は、その分を **連絡遅延金** として請求できるようにしたい。
- 案: 申請を認めるときは、**「事情が分かった時点で連絡していれば、いくらだったか」で計算し直す**。実際の連絡が遅れた分の差額が連絡遅延金として残る。
- 案（2026-10-03 改。検討中）: **「何分を失ったか」は事情（電車・病気）による。「どれだけ急だったか」（率）は連絡の時刻による**。この2つを分ける。
  - 申請を認めたときの率 = **a ＋（連絡を受けた時刻の率 − 分かった時刻の率）**。事情による分は a（体調不良と同じ 25%）まで下げ、連絡が遅れて上がった分は下げない（これが連絡遅延金）。
  - 例（18:00 開始、90分・4,500円、u = 50円。17:30 に電車の遅れが分かり、18:30 着で 30分の遅刻）:
    - 申請なし: 30分 × 50円 × 100% = 1,500円
    - 17:30 にすぐ連絡して申請: 1,500円 × 25% = 370円
    - 18:00 に連絡して申請: 1,500円 × (25% + 100% − 87.5%) = 560円（うち連絡遅延金 190円）
  - 当日の早い時刻（開始3時間より前）に分かっていたのに直前に連絡した場合は、分かった時刻の率が a なので、減額はなくなる（連絡が遅れた分がすべて残る）。
  - 「到着の遅れ − 連絡の遅れ」で原因を分ける考え方も出たが、連絡の遅れで到着が遅れるわけではない。たとえば 15:00 に分かって 15:30 に連絡しても、塾の準備にはほとんど影響しないのに、全部が連絡のせいになってしまう。そこで、連絡の遅れは「率の差」で測る。
  - 連絡遅延金をもっと重くしたい場合は、差額に倍率をかける、最低額を決める、などで調整できる。
  - 例: 電車の遅れが 17:30 に分かった（遅延証明書の時刻）のに、連絡が 17:58。残り時間で決まるキャンセル料（6-1）なら、17:30 時点の額まで下げ、17:58 時点との差額は残す。
  - 「分かった時点」は、遅延証明書の時刻・病院の受付時刻など、証明があればそれを使う。証明がなければ、申請の内容から塾が判断する。
- 以下は、遅刻・遅らせる連絡そのものについての案（申請しない場合）:
- 規約に書く: 遅れることが分かった時点で、**到着見込み時刻**を添えて連絡する。
- 判定を簡単にする案: 開始を遅らせる連絡は **開始30分前まで** に限る。それより後の連絡は「遅刻」として扱う（予定の時刻に終了・全額）。
- 到着見込み時刻より大きく（例 10分以上）遅れた場合は、超えた分を遅刻として扱う。
- 生徒ごとの通塾時間を登録して「家を出る時刻」から判定する方法もあるが、確かめようがないので使わない。

### 6-6. 始める日と、契約の更新（決定: 1か月単位で、毎月双方の確認で続ける。変更は翌月分の確認の前に知らせ、同意しなければ続けない）
- 料金を変えるので、**保護者の明示の同意**を得てから、決めた日以降の授業に当てはめる。これまで免除した分はさかのぼらない。
- 同意の取り方:
  - 案A（おすすめ）: **システムの中で完結**。規約に版（例 2026-11版）を付け、保護者ページで全文を見せて「同意する」を押してもらい、版・日時・アカウントを記録する。規約が変わるたびに同じ流れ。
  - 案B: 外部の電子契約（クラウドサインなど）。証拠としては強いが、費用と手間がかかる。入塾時の契約だけ外部、規約の変更は案A、という組み合わせもできる。
- 契約期間: 期限を設ける（例 1年、更新時に最新の規約に同意）か、期限は設けず「変更は事前に知らせ、同意しない場合は解約できる」とするか。
- 法律面（消費者契約法・定型約款の変更）は、専門家に確認してから確定する。
- **電子の同意と「正本」**: 契約は書面がなくても合意で成り立ち、画面での同意や電子の記録も証拠になる。トラブルになりやすいのは「どの版に、だれが、いつ同意したか」と「どれが正本か」があいまいなとき。対策:
  - 規約に「**正本は保護者ページに掲載し、同意した版とする**」と書く。紙と電子で別々の版を持たない。
  - 同意したときに、**その版の全文の写し（PDF など）をメールで送る**。保護者の手元にも同じものが残る。
  - 同意の記録には、版・日時・アカウント・全文の指紋（ハッシュ）を残し、あとから書き換えられないようにする。
- **特定商取引法（特定継続的役務提供）の確認**: 学習塾は、契約期間が2か月を超え、金額が5万円を超えると対象になり、契約書面の交付・クーリングオフ・中途解約と違約金の上限などの決まりがかかる。今の契約は1か月単位で、続けるときは毎月確認し、前払金もないので対象外と考えられるが、続けて通う実態をどう見るかも含め、専門家に確認する。対象になる場合は、書面（電子交付も可）の要件に合わせる。

### 6-7. 講師への支払い（決定: 一部。割合は別に決める）
- 授業がなくなったら、早めに担当講師に知らせる。
- キャンセル料の一部を講師の報酬に回す。講師がすでに出勤していたか（教室で待っていたか）などで割合を変える。詳しくは報酬の設計と合わせて別に決める。
- 決定: 出勤前で取り消せる場合は 1,000円。
- 検討中: 出勤済み（拘束されていた）場合。拘束された時間で考えるか、予定の授業時間で考えるか。講師が雇用（アルバイト）か業務委託かで、休業手当など法律上の扱いが変わるので確認する。

## 7. システムで作ること（決まったあと）

- キャンセル・遅らせる連絡を受けた時刻（生徒・保護者のページの時刻、または LINE などの時刻を教室が記録）から、上の表で **自動で料金を出して請求に入れる**（今は教室が毎回「規定どおり・減額・免除」を選んでいる）。
- 開始を遅らせたときの料金（遅延金）を足す。遅らせた分数・単価・割合・上限を明細に出す。
- 保護者ページの **減額・免除の申請** に、理由の選択（体調不良・交通機関の遅れ・その他）と、証明の写真（遅延証明書など）を付けられるようにする。
- 生徒ごとの **当日キャンセル・遅刻の記録** の一覧（面談で見せられる形）。
- 規約の版と **同意の記録**（6-6 案A の場合）。
- 授業の前日・当日の予定のお知らせ（予定の勘違いを減らす）。
