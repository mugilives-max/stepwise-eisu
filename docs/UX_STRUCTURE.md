# 画面の組み立て（作り直し v2 の UI/UX）

データと仕組みは段階1〜9でそろった。ここからは「使いやすい構成」に直す。この文書は、画面を作り直す前に決める**全体の組み立て**（入口・まとまり・よく使う流れ）。決まったら、よく使う画面から順に作り直す。

## 1. 考え方

1. **やることが先、情報はあと**。開いた最初の画面に「今日の授業」と「対応すること」が出る。機能の名前ではなく、場面で入口を分ける。
2. **人のことは1か所に**。1人の生徒の予定・記録・宿題・成績・計画・請求は、生徒の画面にまとめる（今は予定・記録・成績・計画・請求の画面にばらばら）。
3. **月の仕事は1か所に**。計画と予定表（翌月）・請求（前月）・報酬（前月）を、月の流れの順に並べる。
4. **操作は押したところで**。一覧はすっきり、操作は押すと下から出る画面で（予定で始めたやり方をすべての画面にそろえる）。
5. **スマホが先**。授業のあとに記録を書くのはスマホ。メニューは下（親指で押せる位置）、パソコンでは左。
6. **言葉と色をそろえる**。仮予定（オレンジ）・決定（青）・実施済み（灰）・対応が要る（オレンジの印）を、どの画面でも同じに。

## 3. スタッフの画面（入口は5つ）

| 入口 | 中身 | 今の画面からの移り先 |
|---|---|---|
| **今日** | 今日・明日の授業（押すと「実施済みにして記録」・前回の記録・引き継ぎメモ）、**対応すること**の一覧（連絡・記録待ち・宿題の確認・届いた成績票・結果待ちのテスト・キャンセル料の判断・承認待ちの計画） | ホーム・記録（記録待ち・宿題の確認）・成績（届いた成績票） |
| **予定** | 月の表と選んだ日（作り直し済み）。仮予定・休み・面談を作る | 予定 |
| **生徒** | 家族ごとの一覧 → **生徒の画面**（概要／予定／記録と宿題／成績／計画と請求／基本情報）。家族の連絡先・保護者ページの招待・プレビューもここ | 家族と生徒・記録・成績・計画（生徒ごとの部分） |
| **月の仕事** | 月の流れの順に「翌月の計画と予定表」「前月の請求」「前月の報酬」。それぞれ進み具合（何家族済み・残り何件）が分かる | 計画・請求・報酬 |
| **設定** | スタッフ・時給と源泉徴収・授業の種類・移行・アカウント | スタッフ・移行・アカウント・報酬の時給 |

- **講師**は「今日・予定・生徒（担当の生徒だけ。計画と請求は出ない）・報酬（自分の明細）」の4つ。
- スマホでは下にこの5つ（講師は4つ）のメニュー。画面の上は、その画面の名前と戻るボタンだけ。

## 4. 保護者の画面（入口は4つ）

| 入口 | 中身 |
|---|---|
| **ホーム** | 次の授業、**やること**（承認待ちの計画・締め切りの近い仮予定・お支払い・宿題）、新しい記録 |
| **予定** | 予定の一覧と「変更・お休みの連絡」、テスト・行事を知らせる（今の「予定の共有」） |
| **学習** | 記録・宿題・成績（成績票を送る） |
| **お支払い** | 計画の承認・請求・振込の連絡・キャンセル料 |

- 子どもが2人以上なら、上で子どもを切り替える（ホームとお支払いは家族全体）。
- アカウント（パスワード・ログアウト）は右上のメニューに。

## 5. 生徒の画面（入口は3つ）

| 入口 | 中身 |
|---|---|
| **ホーム** | 次の授業、今日の宿題（「できた」）、次のテストまで何日 |
| **予定** | 予定と連絡（保護者が許したとき）、テスト・行事を知らせる |
| **学習** | 記録・宿題・成績（成績票を送る） |

## 6. 作り直す順番（案）

1. 画面の枠（下のメニュー・上の帯・下から出る画面）を、スタッフ・保護者・生徒で共通にする
2. スタッフの「今日」（授業のあとに一番使う）
3. スタッフの「生徒の画面」
4. 保護者の「ホーム」と全体
5. スタッフの「月の仕事」
6. 生徒の画面
7. 設定ほか

## 7. 決めたこと（2026-10-02、本人了承）

- スタッフの入口は「今日・予定・生徒・月の仕事・設定」の5つ。
- 講師に見せるのは担当の生徒だけ。計画と請求は見せない。
- 保護者の画面は、子どもを上で切り替える形。

## 8. 進み具合

- **2026-10-02 予定**（作る順番の前に、本人の指摘で先に直した）：月の表に生徒名（生徒ごとにまとめて「×n」、状態の色）、共有予定は帯、選んだ日はすぐ下（パソコンでは横）、授業を押すと下から出る画面。画面の上は不透明で1行。
- **2026-10-02 ① 画面の枠（スタッフ）**：メニューを「今日・予定・生徒・月の仕事・設定」に（講師は「今日・予定・生徒・報酬・設定」）。スマホでは画面の下に固定（アイコンつき）、パソコンでは上。今までの画面（記録・成績・計画・請求・報酬・スタッフ・移行）は、それぞれの入口の下に入り、開くとその入口が光る。「生徒」は今は「家族と生徒」（講師は成績の生徒一覧）を開く（生徒の画面は③で作る）。「月の仕事」「設定」は今は今までの画面への入口（月の仕事の進み具合は⑤）。
- **2026-10-02 ② 今日**（`staff/home.js`、API `home/today`＝`cf/v2/home.mjs`）：対応すること（連絡・記録待ち・引き継ぎメモ・宿題の確認・届いた成績票・結果待ちのテスト・キャンセル料・承認待ちの計画。件数つきで、押すとその画面へ）と、今日・明日の授業。始まった決定の授業は「実施済みにして記録」で記録の画面へそのまま進む。講師は担当の分だけ。
- **2026-10-02 ③ 生徒の画面**（`staff/students.js`、API `students/list`・`students/hub`＝`cf/v2/student-hub.mjs`）：「生徒」は家族ごとの一覧（名前・ふりがなで探す、次の授業・連絡・記録待ちの印）。生徒を押すと #student=<id>/<タブ>。タブは 概要（対応すること・次の授業・前回の記録・引き継ぎメモ・宿題・テスト・今月と来月の計画）／予定／記録と宿題／成績（推移と試験、入力は成績の画面）／計画と請求／基本情報（家族の連絡先。直すのは家族の画面）。講師は担当の生徒だけで、計画と請求・基本情報は出ない。
- **2026-10-02 ④ 保護者の画面**（`family/app.js`）：入口を「ホーム・予定・学習・お支払い」に。スマホでは下のメニュー、アカウントは右上。ホームは やること（計画の承認・承諾の確認・仮予定の締め切り・お支払い・宿題）・次の授業・テスト・新しい記録。予定は一覧と「変更・お休みの連絡」の下に「テスト・行事を知らせる」（前の「予定の共有」）。学習は「記録と宿題」「成績」。子どもが2人以上なら上で切り替え（予定は「全員」も選べる）。前の URL（#events・#grades）も開ける。
- **2026-10-02 ⑤ 月の仕事**（`staff/hubs.js`、API `monthly/overview`＝`cf/v2/monthly.mjs`）：月の流れの順に4つのまとまり。前月分の請求（確定・確定できる・確かめること・入金済み・振込の連絡・お支払い待ち・キャンセル料の判断、自動確定の日、承認のない授業）、翌月の計画（計画なしの生徒・下書き・承認待ち（お願いを送った日）・承認済み）、翌月の予定表（予定なしの生徒・未送信・仮予定・決定）、前月分の報酬（確定できる・確かめること・支払い待ち・支払い済み・担当のない授業）。日付から「今の時期」を枠で目立たせる（1〜2日は請求、〜20日は計画と予定表、21日〜は報酬）。
- **2026-10-02 ⑥ 生徒の画面**（`student/app.js`）：入口を「ホーム・予定・学習」に、スマホでは下のメニュー。ホームは 次の授業・宿題（その場で「できた」）・次のテストまでの日数。予定の下に「テスト・行事を知らせる」（保護者が許したとき）。学習は「記録と宿題」「成績」。前の URL（#events・#grades）も開ける。
- **2026-10-02 ⑦ 設定ほか**（`staff/hubs.js`・`staff/ui.js`）：設定は アカウント（名前・メール）／教室の運営（時給と源泉徴収 #rates・授業の種類と標準料金 #kinds）／システム（スタッフ・移行と切り替え）。時給と授業の種類は、報酬・計画の画面から設定へ移した（報酬・計画には設定への案内だけ）。時給・授業の種類・スタッフは、一覧の行を押すと下から出る画面で直す（スタッフの招待も）。入口の下の画面には左上に「‹ 戻る」（来た道をたどる。直接開いたときはその入口へ）。下から出る画面は Esc でも閉じる。
- **2026-10-02 残りの画面**：記録・成績・計画・請求・報酬・家族も「一覧＋押すと下から出る画面」にそろえた。
  - 記録: 記録待ちは一覧（押すと記録を書く画面）、宿題の確認は下から（確認した／やり直しを伝える。やり直しの内容もそこで書く）。記録を書く画面は保存ボタンを画面の下に貼りつけ、引き継ぎメモを書く・記録を無効にするはたたむ。
  - 成績: 届いた成績票・結果待ちのテスト・取り込み待ちは一覧から下へ。試験の結果を入れる・直すは広い下から出る画面で。「取り込んだ／取り込まない」を押しても画面が更新されなかった不具合を直した。
  - 計画: 計画の行を押すと下に中身と「直す・承諾を記録・消す」。足す・直す・承諾も下から。
  - 請求: キャンセル料の判断・家族ごとの内訳（確定・入金・取り消し）を下から。報酬: 講師ごとの明細（調整・確定・支払い）を下から。
  - 家族: 家族の登録・保護者の情報を直す・生徒の操作（生徒の画面・直す・プレビュー・専用リンク・別の家族へ移す）・生徒を足すを下から。
  - 共通: 描き直しても開いている下から出る画面は動かさない（アニメーションをやり直さない・中のスクロールを保つ）。エラーは下から出る画面の中にも出す。
