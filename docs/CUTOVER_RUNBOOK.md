## 1. いつ切り替えるか

- **2026-10-12（月・体育の日）の朝**に切り替える（2026-10-07 本人の決定。全部を整えてから移行するのではなく、段階に分けて先に公開する。受講規約の改定と講師の雇用契約は公開のあと）。
- 月の途中でもよい。もともと「月初の3日〜5日」としていたのは、前月分の請求を今の仕組みで確定（3日の0時10分）してから写すため。10/12 なら 9 月分は確定済みで、10 月の授業・キャンセル料は移行の道具が写し、10 月分の請求は新しい仕組みが 11/3 に確定する。リハーサルの「照らし合わせ」で 10 月分の件数と金額が合うことを確かめる。
- 授業の少ない日の、授業のない時間（朝など）。作業は1時間ほどを見込む。
- 新しい取消料（率）は settings の `cancelRuleFrom`（2026-11-01）のまま、11 月の授業から効かせる（2026-10-07 本人）。10 月の授業は今までどおり（1,000円 / 授業料を教室管理者が判断）。

- **受講規約は、公開のあとに載せる**（2026-10-07 本人：契約書の完成を待たない）。設定の「受講規約」で版を決めるまで、保護者ページは同意を求めない。版を決めたら、全家族が同意するまで新しい計画を承認できない（見送りはできる）。書面でもらった同意は家族の画面の「同意を記録」で残す。

## 3. 当日の手順

当日の作業の大部分は、新しい管理画面の「移行」→「7. 切り替え」のボタン1つで行います（9段目で作った）。

1. 「移行」で「6. 切り替えの予行」を押し、残っている対応（連絡・キャンセル料の判断）があれば先に済ませる。
2. 「7. 切り替え」で、登録していない家族に案内を送るかを選び、「切り替える」と入れてボタンを押す。ボタンは次を順に行う。
   1. 今の仕組みを「読むだけ」にする。今の画面からの書き込みと、今の仕組みの毎日の自動処理（請求の確定・仮予定の決定）が止まる。管理画面のログインと閲覧は残る。
   2. 最後の「全部を順に写し直す」。
   3. 照らし合わせ。「違う」が出たら、そこで止めて今の仕組みを元に戻す（何も切り替わらない）。
   4. 切り替える（保護者へのメール・カレンダーが動き始める）。
   5. 今日以降の決定の授業・面談で、カレンダーの予定がないものの予定を作る（今の仕組みが作った予定はそのまま引き継ぐ）。
   6. （選んだとき）保護者ページに登録していない家族に、登録の案内を送る。
3. 今の画面は自動で新しい画面に移る（`/hogosha/` → `/family/`、`/yoyaku/?k=` → `/student/?k=`、`/yoyaku/#family` → `/family/`、`/kanri/` → `/staff/`）。保護者・生徒は今のリンクやブックマークのままでよい。今の管理画面を見返したいときは `/kanri/?stay=1`（読むだけ。新しい管理画面のホームにもリンクがある）。
4. 自分で一通り試す（新しい画面でログイン・予定を見る・記録を書く）。保護者・生徒の見え方は「家族と生徒」の「プレビュー」で確かめる（表示だけで、何も変わらない）。
5. 必要なら保護者・生徒・講師に案内を送る（案内文 B・C・D。切り替えたあとは今の仕組みの通知（プッシュ）が届かなくなり、知らせはメールになるので、メールのない家族には伝える）。

## 4. うまくいかなかったとき（戻し方）

- **当日のうち**なら、今の仕組みに戻せる。「7. 切り替え」の「元に戻す」（「元に戻す」と入れる）で、次の2つを一度に行う。
  1. 新しい仕組みの保護者へのメール・カレンダーを止める。
  2. 今の仕組みの「読むだけ」を外す（書き込みと毎日の自動処理が戻る）。
- 新しい仕組みで受けた連絡や記録があれば、今の仕組みに手で入れ直す。新しい仕組みが作ったカレンダーの予定は残るので、要らなければ消す。
- 戻しても、新しい仕組みの台帳は残る。直してから、もう一度「全部を順に写し直す」からやり直せる。
