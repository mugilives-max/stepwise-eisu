# メール通知の一覧

システムが送るメールの正本。誰に・いつ・どんな件名で送るか、どうすれば止まるかをまとめる。
メールを足す・減らす・文面を変えるときは、コードと一緒にこの文書も更新する。

調べた日: 2026-10-01（コード `gas/*.gs` と `cf/worker/*.mjs` から洗い出し）。

## 共通のしくみ

- **送るのは Apps Script**。台帳の正本は Worker（D1）で、Worker はメールを「付随処理」として控え（`_effects`）に記録し、応答を返したあとで Apps Script に送信を頼む。送った記録は管理画面の「設定 → 送信の記録」（`#sendlog`）で見られる。失敗したものは「送れなかった処理」に残り、自動では送り直さない。
- **差出人**は先生の Google アカウント（Apps Script の所有者）。生徒・保護者あての差出人名は「ステップワイズ英数教室」。
- **テストの生徒・家族には実際には送らない**。名前が【テスト】の生徒、テスト用の家族は「送ったことにする」だけ（記録の状態は `suppressed`）。
- **生徒・保護者あての業務メールは、受信確認済みのアドレスにだけ送る**。未確認なら送らずに `skipped` として記録する。
- **本人が種類ごとに止められる**。生徒はマイページの「設定 → メールで受け取る項目」、保護者は保護者ページの「設定 → メール通知」。止めた種類は `skipped`（本人の通知設定でオフ）として記録する。認証・登録のメールは止められない。
- **二重送信を防ぐ**。同じ出来事には同じ通知 ID を付け、同じ ID のメールは二度送らない。送信結果が分からなくなったものは `uncertain` にして自動では再送しない。
- **1日の送信上限**（Apps Script の上限）に達したら送らず `failed` にする。
- 記録の場所: 生徒あて `studentEmailOutbox`、保護者あて `familyOutbox`（どちらも台帳）、送信そのもの `_effects`（Worker）。

## 生徒あて（業務のお知らせ）

| 種類（設定のキー） | 件名 | 送るとき | 本文 | 止め方 |
|---|---|---|---|---|
| 授業の案内（`offered`） | 【ステップワイズ】授業の案内が届いています | 先生が授業を案内したとき（管理画面の案内、くり返し・連続を含む。MCP からの案内も同じ） | 案内した日時・科目・形式の一覧。専用リンクは書かない | 生徒の設定で「授業の案内（新しい授業の日時）」をオフ |
| 授業の変更（`changed`） | 【ステップワイズ】授業の予定を変更しました | 先生が授業の中身を変えたとき。案内中の授業の修正、確定した授業の日時変更、科目の修正、授業形式（対面・オンライン）の変更のどれでも送る（見直し候補 7） | 変更前と変更後 | 「授業の変更（日時・科目・形式）」をオフ |
| 授業の取消（`cancelled`） | 【ステップワイズ】授業を取り消しました | 先生が確定した授業を取り消したとき（欠席・キャンセルの登録、生徒の取消依頼を承認）。返事前の案内を取り下げたときは送らない（2026-10-01 から） | 取り消した授業の日時 | 「授業の取消」をオフ |
| 取消依頼の却下（`cancelDeclined`） | 【ステップワイズ】授業は予定どおり行います | 生徒の取消依頼を先生が承認しなかったとき | 対象の授業の日時 | 「取消依頼への回答（予定どおり実施）」をオフ |

## 保護者あて（業務のお知らせ）

件名はどれも「【ステップワイズ】（年月）保護者ページのお知らせ」。本文は1行の案内と保護者ページの URL だけで、金額や授業の中身は書かない。

| 種類（設定のキー） | 本文の1行目 | 送るとき | 止め方 |
|---|---|---|---|
| 授業計画の確認依頼（`planProposed`） | 授業計画(回数・料金)の確認依頼があります。 | 先生が授業計画の行を保護者に送ったとき（「下書きを保存」では送らない） | 保護者の設定で「月の回数・料金の確認依頼」をオフ |
| 請求の記録（`invoiceCreated`） | 授業料の請求内容を記録しました。 | 先生が管理画面で請求を記録したとき（請求ページ・生徒ページ）。**毎月1日の自動締めでは送らない**（見直し候補 4） | 「請求の記録」をオフ |
| 請求の取消（`invoiceVoided`） | 授業料の請求を取り消しました。 | 先生が未入金の請求を取り消したとき | 「請求の取消」をオフ |

送る相手は、その生徒に紐付いていて、メール確認が済み、利用中の家族アカウント全員。

## 認証・登録のメール（止められない）

| 相手 | 件名 | 送るとき | 有効期限 |
|---|---|---|---|
| 生徒 | 【ステップワイズ】生徒メールの受信確認 | 生徒がマイページでメールアドレスを登録・変更したとき | 30分 |
| 保護者 | 【ステップワイズ】保護者メールの確認 | 保護者が自分で登録を始めたとき・メールアドレスを変えたとき | 30分 |
| 保護者 | 【ステップワイズ】保護者ページの登録案内 | 先生が管理画面で保護者のメールアドレスを入れて「登録メールを送る」を押したとき | 24時間 |
| 保護者 | 【ステップワイズ】パスワード再設定 | 保護者がパスワードの再設定を申し込んだとき | 30分 |
| 先生 | [ステップワイズ] 管理画面のパスワード設定コード | 管理画面の初期設定・パスワード再設定で「コードをメールで送る」を押したとき（送り先は Apps Script の所有者に固定） | 15分 |

講師アカウントの招待はメールでは送らない（設定ページで出るリンクを先生が LINE などで渡す）。

## 先生あて（業務のお知らせ）

先生の Google アカウントに届く。件名の頭は「[ステップワイズ予約]」。台帳の設定 `emailNotify` が `on` のときだけ送る（2026-10-01 時点で on）。種類ごとには止められない。テストの生徒の出来事では送らない。

| 件名 | 送るとき |
|---|---|
| 【確定】（生徒名）さん N件 | 生徒が案内を承認して授業が確定したとき。**先生が生徒の承認を待たずに登録したときも、自分あてに届く**（見直し候補 2） |
| 【日時が合わない】（生徒名）さん | 生徒が案内を「日時が合わない」と断ったとき |
| 【取消依頼】（生徒名）さん | 生徒または保護者が授業の取消依頼を出したとき（2026-10-01 から）。日時・科目・理由と、無料で取り消せる期限（前日23時）を過ぎた依頼かどうかを書く。同じ依頼の再送では送らない |
| 【取消依頼の取り下げ】（生徒名）さん | 生徒が出した取消依頼を自分で取り下げたとき |
| 【共有予定】（生徒名）さん | 生徒がマイページで予定（テスト・行事など）を共有したとき（先生が登録した予定では送らない） |
| 【授業希望】／【授業希望・要調整】（生徒名）さん | 生徒が授業できる時間帯（希望）を送ったとき（保護者の代理入力では送らない） |
| 【授業計画の回答】（生徒名）さん … | 保護者が授業計画を承認・回数調整・見送りしたとき |
| 【授業計画の問い合わせ】（生徒名）さん … | 先生が記録した承認について、保護者が「先生に問い合わせる」を押したとき |

ほかに、仕組みの異常を知らせるメールがある（`emailNotify` に関係なく送る）。

| 件名 | 送るとき |
|---|---|
| [ステップワイズ] シートへの写しが N 回続けて止まっています | 台帳をスプレッドシートへ写す処理が失敗し始めた日と、その後7日おき |

## メールでは送らないもの

- **返事前の案内の取り下げ**: 生徒へのメールは送らない。生徒のページから案内が消えるだけ（2026-10-01 から）。
- **授業記録の公開・宿題の反映**: メールは送らない。生徒・保護者のページに出る。
- **毎月1日の請求の自動締め**: メールは送らない。保護者ページの「請求・お支払い」に出る。
- **保護者からの振込の連絡**: 先生へのメールはない。管理画面の請求ページに「入金の確認待ち」として出る。
- **連絡欄（生徒・保護者からのメッセージ）**: メールは送らない。

## メール以外の通知（アプリの通知）

ホーム画面に追加したアプリで通知を許可した端末にだけ届く（Web プッシュ、`cf/worker/push.mjs`）。メールとは別に、次の2つだけ。

| 相手 | 表題 | 送るとき |
|---|---|---|
| 生徒 | 授業の案内が届きました | 先生が授業を案内したとき |
| 保護者 | 学習計画の承認のお願い | 先生が授業計画を保護者に送ったとき |

## 見直し候補（2026-10-01 に洗い出したもの）

不要なメールや分かりにくいメールになっていそうな所。直すかどうかは先生が決める。

1. ~~返事前の案内を取り下げても「授業を取り消しました」が届く~~ → **対応済み（2026-10-01）**: 取り下げではメールを送らない。
2. **先生が生徒の承認を待たずに登録した授業**で、生徒には先に「授業の案内が届いています」が届き、確定のメールは届かない。案内に返事が必要だと誤解されうる。先生自身にも【確定】メールが届く（自分の操作の通知）。
3. ~~保護者あての請求メールの文面が「月謝」のまま~~ → **対応済み（2026-10-01）**: 「授業料の請求」に直した。
4. **請求のメールが、手で記録したときだけ届き、毎月1日の自動締めでは届かない**。保護者から見ると月によって届いたり届かなかったりする。どちらかに揃える。
5. ~~生徒の取消依頼が新しく出されても先生にメールが来ない~~ → **対応済み（2026-10-01）**: 【取消依頼】を先生に送る。
6. **先生あての通知は種類ごとに止められない**（`emailNotify` の一括 on/off だけ）。不要な種類があれば、種類ごとの設定を作る。
7. **科目の書き間違いを直しただけでも「授業の予定を変更しました」が届く**。日時・形式の変更は知らせる必要があるが、科目だけの修正は送らない案。
