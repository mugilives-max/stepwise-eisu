# 契約書(受講規約)に追加する条項の下書き

作成: 2026-09-06。方式 A(月ごとの授業回数を保護者が事前承認)に合わせた案。法的な文言の最終確認は専門家にお願いしてください。

**未確定の条項案**。契約更新を検討するときに参照する。条項の確定・既存保護者の同意方法は [FUTURE_WORK.md](FUTURE_WORK.md#契約書の更新) で管理する。認証の実装完了は、この条項の採用や月間承認のAPI制御の完了を意味しない。

## 1. 授業回数の事前承認

1. 塾は、毎月の授業予定回数(科目ごと)を前月末までに保護者に提示します。
2. 保護者は、マイページの保護者ページで承認するか、LINE・電話・対面で承諾を伝えます。塾は承諾の方法と日時を記録します。
3. 承認された回数の範囲内で授業を実施し、授業料を請求します。回数を超える授業や追加の授業は、あらためて保護者の承諾を得てから実施します。
4. 月の途中で回数を変更する場合は、変更後の回数について再度承認を受けます。

## 2. 授業の予定と実施

1. 個々の授業日時は、塾から生徒・保護者へ案内し、生徒または保護者がマイページで確定します。
2. 確定した授業の取消は、授業開始の24時間前までにマイページから依頼してください。24時間を切った取消、および連絡のない欠席は、実施済みとして扱うことがあります。
3. 塾は実施した授業をマイページに記録します。保護者はいつでも実施状況を確認できます。

## 3. 保護者ページとパスワード

1. 保護者ページは保護者専用のパスワードで保護されます。パスワードは保護者ご自身が設定・管理し、塾はその内容を知りません。
2. 初回設定および再設定は、塾が発行する設定コード(有効期限付き)を用いて保護者が行います。
3. パスワードは家族以外に共有しないでください。共有によって生じた閲覧・操作について塾は責任を負いません。

## 4. 連絡手段

1. 日程の案内・確定・取消などの連絡は、マイページと LINE(必要に応じてメール)で行います。
2. 保護者は、連絡先の変更があった場合は速やかに塾へ知らせてください。

## 5. 情報の取り扱い

1. 生徒の氏名、学年、学校、成績、模試結果、授業の予定と実施記録、授業料と入金の記録は、塾の管理システム(Google のサービス上)に保管します。
2. これらの情報は授業の実施、進路指導、請求の目的にのみ使用し、第三者に提供しません。
3. 保護者・生徒は、自分に関する記録の閲覧をマイページで行えます。誤りがあれば塾に修正を求めることができます。

## 6. 授業料

1. 授業料は、承認された回数に基づく実施済みの授業について、月末に計算し翌月に請求します(月謝制の場合は定額)。
2. 請求と入金の状況は保護者ページで確認できます。
