# 課題と Future Work

設計・実装の途中で「ここは後で」「ここが気になる」と思ったことを忘れないための一覧。
最終更新: 2026-09-07。システム全体は [SYSTEM.md](SYSTEM.md)、MCP は [MCP_DESIGN.md](MCP_DESIGN.md) / [MCP_OPERATIONS.md](MCP_OPERATIONS.md)。

## 書き方のルール

- 1項目 = 見出し1つ。**背景**(なぜ課題か)、**やること**、**関連**(ファイル・シート)、**追加日** を書く。決まっていないことは「未定」と書いてよい。
- 作業中に気づいた課題は、その場でこのファイルに追記する(AI が作業したときも同じ)。小さなことでも書く。
- 着手したら見出しの先頭に `[着手中]`、終わったら「済み」の節へ移し、日付とコミット/GAS バージョンを添える。
- 優先度は A(運用に支障・安全性)/ B(あると楽になる)/ C(いつか)の3段階。

## A: 優先度が高い(安全性・運用に直結)

### 保護者専用パスワード(決定済み・未実装)
- **背景**: いまの保護者ページのパスワードは先生の管理ログインと同じ。保護者が承認する仕組みとして弱く、契約更新(方式A)の前提にもなる。2026-09-06 に方式を決定済み。
- **やること**: `parents` シート(studentId, passSalt, passHash, setAt, lastLogin, failCount, lockUntil)。先生は管理画面で6桁の設定コード(24時間有効)を発行して LINE で伝え、保護者がマイページ「保護者」タブで自分のパスワードを決める。先生には「設定済み/未設定・最終ログイン」だけ見える。ログイン失敗回数によるロック。
- **関連**: `gas/Code.gs` parentLogin / parentData、`yoyaku/index.html` renderParentPage、`kanri/index.html` カルテ、SYSTEM.md 4章。
- **追加日**: 2026-09-07

### 月の授業回数(方式A)の本運用開始
- **背景**: 「月ごとの授業回数を保護者が事前承認」を正式運用と決めたが、実生徒は全員 planStatus が none(計画未設定)のまま。承認がないと請求できない前提なので、運用に乗せないと画面の案内文とずれる。
- **やること**: 実生徒3名の今月・来月の回数を planSet → planPropose し、保護者に承認してもらう(保護者パスワードの実装後が自然)。承認前の月に授業を実施したときの扱い(遡り承認)をルール化。
- **関連**: `gas/Code.gs` planSet / planPropose / planApproveTeacher / parentPlanDecide、`plans` シート。
- **追加日**: 2026-09-07

### 契約書の更新
- **背景**: 方式A と保護者パスワードに合わせて契約条項を変える必要がある。条項案は作成済み。
- **やること**: `docs/CONTRACT_CLAUSES_DRAFT.md` を確定し、既存の保護者へ差し替え・同意の取り方を決める(書面か、マイページ上の同意記録か)。
- **関連**: Drive「02_契約・規約」。
- **追加日**: 2026-09-07

### バックアップの自動化
- **背景**: バックアップは「Drive のスプレッドシート2つを手でコピー」だけ。消し間違い・誤上書きへの備えがない。
- **やること**: Apps Script の時間主導トリガーで週1回、2つのスプレッドシートを「99_アーカイブ/backup」へコピー(世代は8つまで)。`log` / `mcpLog` シートの肥大化対策(古い行を月次でアーカイブ)も同時に。
- **関連**: `gas/Code.gs`(新関数)、Drive「99_アーカイブ」。
- **追加日**: 2026-09-07

- **背景**: `gas/Code.gs` はエディタに全文貼り付けて新バージョンをデプロイしている。AI 経由だとブラウザ操作(Monaco への差分適用)が必要で時間がかかり、貼り忘れで GitHub と本番がずれる恐れがある。

### GitHub Pages のキャッシュ対策
- **背景**: HTML がブラウザに約10分キャッシュされ、生徒に「更新したのに変わらない」が起きうる。確認時は `?nc=` を付けている。
- **やること**: 大きな変更のときに生徒へ再読み込みを促す仕組み(GAS の state にフロントの版番号を含め、古ければバナー表示)か、`Cache-Control` を短くできる配信先の検討。
- **関連**: `yoyaku/index.html` loadState。
- **追加日**: 2026-09-07
