作成: 2026-10-01（同日、言葉を整理して改訂）。**案の段階**で、まだ採用していない。採用前に専門家（消費生活センター、行政書士・弁護士など）に確認する。確認してほしい点は末尾にまとめた。

仕組みの設計は [SCHEDULING_FLOW_DESIGN.md](SCHEDULING_FLOW_DESIGN.md)。古い条項案 [CONTRACT_CLAUSES_DRAFT.md](CONTRACT_CLAUSES_DRAFT.md) はこの案で置き換える。

## この改定の考え方

- 契約は **1か月ごと** にする。その月の授業計画（回数・料金）を保護者が承認すると、その月の約束が成り立つ。決まった曜日の授業や、何か月も続けることは約束しない。
- 授業料は今までどおり **実施した授業の分だけを後払い** にする。固定の月謝はない。
- 日程は塾がまとめて送り、締め切りまでに連絡がなければ決定する。
- **言葉を分ける**。前日23時までに日時を変えるのは「日時の変更」、その授業を行わないことにするのは「お休み」で、どちらも無料。前日23時を過ぎてから授業を行わないことにするのが「キャンセル」で、キャンセル料がかかる。「振替」という言葉は使わない（振替を受ける権利があるように読めるため）。
- キャンセル料の金額は今の契約のまま変えない。
- 請求は翌月3日に確定する（1日・2日は塾が内容を確かめる期間）。

【】の部分は、先生が決めて埋める。

## 受講規約（案）

### 第1条 契約の単位

1. 受講の契約は、1か月（暦の月の1日から末日まで）ごとに結びます。
2. 塾は、翌月の授業計画（科目・授業の種類・回数・1回の時間・1回の授業料）を、原則として前月の20日ごろまでに保護者ページでお知らせします。
3. 保護者が授業計画を承認したときに、その月の契約が成り立ちます。保護者ページでの承認のほか、LINE・電話・対面で承諾をいただいた場合は、塾がその日時と方法を記録し、保護者ページに表示します。
4. 契約は自動では更新されません。翌月の授業計画を承認されなかった場合、翌月の授業はありません。
5. 月の途中で回数を増やす場合（テスト前の追加など）は、追加の授業計画をお知らせし、承認をいただいてから実施します。

### 第2条 授業予定日の決め方

1. 塾は、授業計画とあわせて、その月の授業の予定表をお知らせします。決定する前の授業を「仮予定」と呼びます。
2. 予定表には締め切りを記載します。締め切りは原則として前月の25日です。お知らせが遅れた場合は、お知らせした日から3日後とします。
3. 都合の悪い仮予定があるときは、締め切りまでに、その授業の「変更・お休みの連絡」から、日時の変更をお願いするか、お休みにしてください。LINE での連絡でもかまいません。日時の変更は、塾が別の日時を相談します。
4. 締め切りまでに連絡がなかった仮予定は、その日時で決定します。決定したことは生徒のページと保護者ページに表示し、メールでもお知らせします。
5. 予定表に含まれない授業を、月の途中で塾がお知らせすることがあります。この場合もお知らせに締め切りを記載し、同じ扱いとします。授業の日が近く締め切りを設けられない場合は、生徒・保護者と連絡のうえで塾が決定し、そのことをお知らせします。

### 第3条 決定した授業の日時の変更とお休み

1. 決定した授業は、授業日の前日23時までにご連絡いただければ、無料で次のどちらかにできます。
   - 日時の変更: 別の日時に移します。変更後の日時は、生徒・保護者と塾で相談して決めます。
   - お休み: その授業を行いません。
2. 塾の予定によっては、ご希望の日時に変更できないことがあります。その場合は、お休みにするか、元の日時で実施します。
3. 期限の判定には、生徒のページ・保護者ページで連絡を受け付けた時刻、または塾が記録した LINE などでの連絡の時刻を使います。
4. 期限を過ぎてからは、第4条（当日の開始時刻の変更・遅刻）または第5条（キャンセル）のとおり扱います。

### 第4条 当日の開始時刻の変更と遅刻

1. 授業日の前日23時を過ぎてから、授業の開始を遅らせてほしいというご連絡があった場合、塾の都合がつくときに限り応じます。応じるかどうかは塾が判断します。
2. 前項により開始を遅らせた場合、授業料は元の予定どおりの時間分とし、追加の料金はいただきません。塾はその旨を記録します。
3. 前項のご連絡がたびたび続く場合は、今後の日程の決め方について保護者と相談させていただくことがあります。
4. 生徒が授業に遅れた場合（第1項により開始を遅らせた場合を除きます）、授業は予定の終了時刻に終わり、授業料は予定どおりの時間分をいただきます。

### 第5条 キャンセル

1. 授業日の前日23時を過ぎてから、決定した授業を行わないことにする場合を「キャンセル」といいます。連絡のない欠席もキャンセルとして扱います。
2. キャンセル料は次のとおりです。
   - 授業の開始時刻より前のご連絡: 1回 1,000円
   - 授業の開始時刻以降のご連絡、および連絡のない欠席: その授業の授業料相当額
3. 急な病気など、やむを得ない事情があるときは、塾の判断でキャンセル料を減額・免除します。キャンセルのあとに、保護者ページから減額・免除を申請することもできます。
4. 期限の判定は第3条第3項と同じです。

### 第6条 塾の都合による変更・休講

1. 塾の都合で授業の日時を変える場合は、できるだけ早くお知らせし、別の日時を相談します。料金はかかりません。
2. 塾の都合で授業を行えない場合、その授業の授業料はいただきません。

### 第7条 担当講師

1. 授業は塾の代表者、または塾が指導を任せた講師が担当します。
2. 担当講師は月ごとに決め、授業計画とあわせてお知らせします。月の途中で担当を変える場合は、事前にお知らせします。

### 第8条 授業料の請求と支払い

1. 授業料は、承認された授業計画に基づき、その月に実施した授業の分を計算します。キャンセル料も同じ請求に含めます。
   - 1回の授業料は授業計画の「1回の授業料」です。生徒・保護者と塾が相談して授業の時間を計画と変えた場合は、「1回の授業料 ×（実施した時間 ÷ 計画の1回の時間）」とし、1円未満は切り捨てます。遅刻や開始を遅らせた場合（第4条）は、予定どおりの時間で計算します。
2. 請求は翌月3日に確定し、保護者ページでお知らせします。1日と2日は、塾が請求の内容を確かめる期間です。
3. 授業計画の承認がない授業は請求しません。承認をいただいたあと、その月または翌月以降の請求に含めます。
4. お支払いは【方法】で、【期日】までにお願いします。
5. 請求と入金の状況は保護者ページでご確認いただけます。

### 第9条 受講の終了

1. 翌月の授業計画を承認されなければ、翌月から受講はありません。特別な手続きは要りません。
2. 月の途中でやめる場合は、塾にご連絡ください。実施した授業の分とキャンセル料だけを請求し、それ以外の料金はいただきません。

### 第10条 連絡の方法

1. 予定・計画・請求のお知らせは、生徒のページ・保護者ページとメールで行います。メールは受信確認がすんだアドレスに送ります。
2. 日々の連絡は LINE でも受け付けます。決まった内容は、塾がシステムに記録してページに表示します。

### 第11条 情報の取り扱い

（[CONTRACT_CLAUSES_DRAFT.md](CONTRACT_CLAUSES_DRAFT.md) の「5. 情報の取り扱い」と「3. 保護者ページとパスワード」を引き継ぐ。保管場所の記述は今の仕組み（Cloudflare と Google のサービス）に合わせて直す。講師が見られる情報の範囲も書き足す。）

## 専門家に確認してほしいこと

1. **特定継続的役務提供に当たらないか。** 1か月ごとの契約（第1条）で、自動更新がなく、毎月の承認がある。この形で「契約期間が2か月を超える」に当たらないか。実際には何か月も続く生徒が多いことが判断に影響するか。
2. **授業計画の期間。** 今の仕組みでは、授業計画の1行を最長1年の期間で作れる。単月の契約にするなら、通常の計画は暦の月の中、講習などの計画も2か月以内に絞るべきか（設計文書の段階3）。
3. **入会金・教材費。** ある場合、金額の判定に含まれるか。
4. **締め切りでの決定（第2条第4項）。** 連絡がないことをもって日程が決定する扱いが、消費者にとって不利な条項とみなされないか。料金に関わる授業計画は、明示の承認を必要とする形にしてある。
5. **当日の開始時刻の変更（第4条）とキャンセル（第5条）の文面。** 金額や扱いが妥当か。前日23時までのお休みを無料にしている点（第3条）も含めて。
6. **今の生徒への切り替え方。** 一斉に再契約するか、翌月の授業計画の案内と一緒に新しい規約を示して承認をもって同意とするか。
